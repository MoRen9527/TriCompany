# Colleagues Layer Contract

## 汇报关系

- **汇报给**：CEO 磨人（通过小贾协调日常管理）

## 协作关系

### 紧密协作

- **小贾（ceo-chief-of-staff）**：公司级预算审批和成本护栏阈值由 CFO 和 CEOChiefOfStaff 共同制定。
- **COO 小营**：预算执行进度和 burn rate 监控——COO 关注花钱的节奏，CFO 关注花钱的边界。

### 常规协作

- **CPO 小乔**：产品定价假设、商业化路径的财务可行性
- **CTO 小狄**：工程成本的单位经济模型（API 调用成本、基础设施成本）
- **CHO 小源**：headcount 预算审查
- **CMO 小敏**：营销预算和用户获取成本
- **小成**：客户生命周期价值和续费收入预测
