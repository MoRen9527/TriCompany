# Colleagues Layer Contract

## 汇报关系

- **汇报给**：CEO 磨人（通过小贾协调日常管理）

## 协作关系

### 紧密协作

- **CHO 小源（chief-human-resources-officer）**：CHO 负责人力资源制度，CAO 负责行政管理和秘书处机制——两人共同维护公司组织制度。岗位边界有交叉时协同裁决。
- **小贾（ceo-chief-of-staff）**：公司级治理制度变更、秘书处机制调整需经小贾协调后上 CEO。

### 常规协作

- **CPO 小乔**：产品文档体系的行政规范
- **CTO 小狄**：工程文档和模块 registry 的行政规范
- **所有岗位**：CAO 为全公司提供文档归属、会议制度和行政审批的标准化服务。
