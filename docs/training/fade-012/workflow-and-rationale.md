## 一、双通道工作流（拆自 fade-001/02 旅程 B）

**作为助理（事件驱动主）**：销账/交付/裁决后，随手向 `daily-progress.md` 当日节 append 主叙事行 + registry 变化行，与状态条同批 push 三端。约束：只更新自己的主叙事与全节组织权，不碰巡检块；同日已有节则续写不新建。这就是"权威叙事在人、粗粒度镜像在仓"的分工——机器本地不入仓的台账/记事本才是权威细节，daily-progress 是恢复锚。

## 二、灾后重建（拆自 fade-001/02 旅程 D——这套系统的存在意义）

最坏场景：本地+sg+中枢全灭。恢复路径=从 GitHub 取最近的 `daily-progress.md`，按当日节的 commit 清单与挂账行重建工作现场——丢失窗口≤10 分钟（巡检节奏上限）。这是登记册写死的验收场景，不是宣传语；每周的巡检补写都在为这个场景演练。

## 三、设计理据三题（拆自 fade-001/04 §一.1/§一.2/§一.3·09-05 基线原文）

### 1. 为什么每日进度维护用"事件驱动主+定时兜底"双通道，不干脆全自动？

语义与确定性的分权（与 FADE-002"机器永不写摘要"同一价值观的实例化）：
**"哪件事值得记、怎么概括"是语义判断**——做裁决的人记，质量最高，这是事件驱动主；
**"人会不会忘"是概率问题**——确定性脚本每 10 分钟兜一次底，这是巡检。单通道各有死穴：
纯人写=23 小时丢失窗口（旧节奏实测）；纯机器写=没人看得懂的 commit 流水，不是"进度"是"监控"。
双通道靠**单写者三原则**（主叙事权威在人、巡检只追加、冲突退让跳轮）把两种笔迹装进同一份文件。

### 2. 为什么门限用 git 拓扑不用时钟？

`git log <上次触碰>..HEAD` 的 DAG 可达性天然免疫两类时间戳盲区：**同秒提交**（20:20 skip
实测抓出：rebase 连发使 marker 与进度提交同秒，"严格大于"漏计）与**变基重写**（commit
日期被重写后时间戳判据全乱）。教训已从代码层升格为价值观层——D-04 时刻纪律"禁从上下文
时间戳外推"与这是同一条原则的两个投影：**时间戳当参考，拓扑/契约当证据**。

### 3. 为什么推送分两级（sg-bare 必达 / GitHub 尽力而为）？

因为两端的失败语义不同：sg-bare 是**内网必达端**（巡检的直推目标，失败=真故障，如实报
fail 留 recovery push 自愈）；GitHub 是**公网容差端**（服务器无凭据，失败属设计内降级，
≤24h 收敛口径，由事件驱动写收敛补齐）。评分体系为此专设 T5 口径"离线=不可验非 FAIL"——
**失败要分设计内降级与设计外故障，否则兜底通道会被误判为持续故障而失去信任**。

## 五、案 a 复盘：良性分叉 union 归账（拆自 fade-001/04 §三案 a·09-05 基线原文）

### "分叉是双写拓扑的常态，不是事故"

**弧线**：sg watcher 与本机助理双写同一份 daily-progress，跨端推送形成分叉。两例处置：

- **先例**（09-03 凌晨）：sg watcher 02:20 兜底块 b954dffe 与本地分叉 → merge union 归账
  **54294fca**。两笔内伤与对策：①首版 dc8bab38 **误收冲突标记入库**（本地未推即 amend
  修复）——教训=校验断言失败必须中断整条命令链，不许带着红灯继续跑（后升格 D 系纪律）；
  ②commit 附带勘正一条拓扑认知：「watcher 在 sg 检出运行**不受本机脏树影响**」——双写
  两端环境隔离，本机工作区脏不脏与兜底无关。
- **今晨例**（09-04/05 之交）：435188a3（22:30 补写）/a703ea23（00:10 补写）→ 本地 merge
  union 归账 **0335fb62**（双收官叙事+09-05 节并存；**冲突标记 grep=0 验净**——先例教训
  已内化为验收步骤）。

**为什么"良性"**：分叉零丢失——巡检块居前、主叙事殿后、同节去重日期头，双保留合成。
**教训**：双写拓扑下分叉会反复发生，归账不是临时手段而是**纪律**：union 合成+冲突标记
grep=0 验净+归账 commit 留锚。看到分叉第一反应不是"谁搞坏了"，而是"按纪律归账"。

### 案 a 共性教训（并入公司教训检查单·随案 a 同迁）

1. **分叉/断裂是常态不是异常**——设计归账与暴露机制（union 纪律），不设计"永不分叉"。
2. **断言失败须中断整条命令链**（dc8bab38 冲突标记入库教训）——带红灯继续跑=把校验变成装饰。
3. **环境隔离要写进认知**（watcher 在 sg 检出运行不受本机脏树影响）——别用自己的本地状态推断远端行为。
