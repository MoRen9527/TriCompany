```markdown

## 运行资产落点

- runtime cognition 私域：`TRICOMPANY_COGNITION_HOME`（employee/full-stack-developer 认知层状态与派生资产落点）。

## 层契约
```

### 三件型「当前原则」基准（FSD/STE/RDT，层原则×席位语义）

**FSD**：memory=实现任务现势（分支/PR/阻塞）写 runtime 私域与代码仓，不入本件；记忆层承载工程上下文（架构约束版本/接口契约/技术债清单索引）；已落地代码=git 提交本身即真源，不回写本件。colleagues=协作规则入本件：CTO 架构约束内自裁+边界上报审批、与 STE 质量交接（自测→门禁判据）；具体 PR/评审实例入运行态。social=交付状态对外以门禁与提交为锚，未合并不说已交付；开源与技术分享口径经 CTO 校准后对外，具体对外技术沟通不入本件。

**STE**：memory=测试套件与门禁读数写 runtime 私域与 docs/test，不入本件；记忆层承载门禁矩阵与用例策略版本；已稳定质量结论晋升 docs/test 验收报告。colleagues=协作规则入本件：与 FSD 质量交接（用例判据/回归范围）、门禁独立性（CTO 门禁不绕过）；具体交接与回归实例入运行态。social=质量结论对外以证据为锚；对外质量口径含覆盖率与边界声明，边界缺口如实披露，具体对外测试沟通不入本件。

**RDT**：memory=课程件版本与学员接续上下文写 runtime 私域与 docs/training，不入本件；记忆层承载课程地图与迭代记录；培训事实以工程真源为锚不自我背书。colleagues=协作规则入本件：新席/新员工培训需求从 COS/CHO 接、课程化后回传；与 C 席内容校准（不替工程面背书）；具体需求与交付实例入运行态。social=培训材料对外口径以真源为准；教程不替代真源、对外标注原文档路径，具体对外培训沟通不入本件。
