# TriCompany Company Bootstrap Phase 0 Plan

日期：2026-04-16
状态：已启动

## 目标

把 TriCompany 从空仓启动为可继续研发的赛博公司孵化仓。

## 本阶段范围

- 建立根说明与模块规则
- 建立产品、技术、registry、workflow、execution 文档基线
- 建立首版总助 agent 套件与会议 prompt
- 明确进入 TriCompany 内 Hermes 融合与 .github 宿主迁移的下一步入口

## 输入

- TriMetaverse 中现有赛博公司真源
- 总助现有 contract、soul、memory 和会议 prompt
- 对 Hermes 记忆分层的研究结论

## 输出

- TriCompany 首版文档骨架
- TriCompany registry agent
- TriCompany 首版总助套件
- 当前阶段 Hermes 融合与 .github 宿主迁移的下一阶段入口

## 风险

- 空仓起步时容易把“研发草案”和“正式运行状态”写混
- 若不先清楚区分研发仓与宿主仓，后续 Hermes handoff 会返工

## 验收方式

- 核对关键文件是否已创建
- 核对产品 / 技术 / registry / 总助套件是否齐全
- 核对是否已明确下一步进入 TriCompany 内的 Hermes 融合与 .github 宿主迁移阶段
