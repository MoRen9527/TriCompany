## 二、财务护栏与阈值（CFO 面）

### 2.1 阈值分层：单席口径→总额口径联动

- **单席口径（现行在役，不新立）**：授权矩阵现行分层直接适用——recurring cost >10 USD/月、一次性新增 >100 USD 走升级链（CEOChiefOfStaff→董事会）；值班位月度耗用按此口径对表。
- **公司级月度 token 总额护栏（聚合面，LG-033 M→I 演进触发）**：每加挂一席（值班位→员工 session 级全在线），总额口径重新核算一次。**初值设定（建议值候 CEO 批）**：首月观察期只记不设限（读数先行，禁拍脑袋定数）；自第二个月起按首月读数 P50×1.5 定初值；超限=升级人工裁**不硬断**——值班位急件处置不可因预算闸断链，断链风险大于超支风险。

### 2.2 止损阀（五件之②，硬要件）

- **首选形态**：GLM 平台侧 per-key 支出上限/配额——泄露损失从无界变有界的唯一机械手段。**建议初值（候 CEO 批）**=值班位月度预期耗用×2（正常耗用+单次被盗刷余量），触发即平台侧断供+走轮换流程（§一之④），不依赖人工发现。
- **降级形态（平台不支持 per-key 配额时的实勘前置）**：独立预付额度账户隔离——预付额即损失上限（充多少最多损失多少），与本地开发账户物理分账。实勘项：GLM 平台配额机制支持度，候 CAO 治理结构节对齐平台实盘后定形态。

### 2.3 耗用记账落点细则（五件之⑤）

- **双源归因**：第一源=GLM 平台侧按 key 用量报表（key 单列后天然可归因）；第二源=值班位会话侧 token 计量（升级日志分区+会话日志行）。**两源月度对表，差值 >10% 查因**（防计量漂移/盗刷漏检）。
- **落点（零新建立面，低预算阶段不建重账本）**：周粒度读数入当周 operating records（与 P4' 财务读数门三读数——周 token 耗用/唤醒次数趋势/sg 资源水位——同源同载体，COS 面既有通道）；月粒度对表结论随晨检/周平面记录留痕。**独立账本文件暂不设**（YAGNI：token 读数连续两个月在卷后再议必要性）。
- **取数口径**：P4' 转正判据的财务读数一律取自本节双源，禁凭会话印象估读。

### 2.4 波次联动

- Wave 0（P1 auth 补发）=本正身批文前置（批文到才补发，与 COS 排程一致）；P2 开跑起值班位耗用记账即生效——**读数从第一天开始积累**，P4' 观察周不缺数。
- M→I 演进接口：逐席放行制财务侧=§2.1 总额重核算+§2.2 止损阀逐席复制（缺一席不放一席）。
