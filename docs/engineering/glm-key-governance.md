## 一、治理结构（CAO 主笔）

### 1.0 权威源立法（CEO 方向修正令 2026-09-08 并入）

- **TriModel keys 库=key 权威源**：真 GLM key 由 keys 库统一持有（多账号枚段形态，lg006-quota-relay-design-draft 机制锚）；服务器会话 auth 走 **TriModel 网关通道**（`TRIMODEL_API_TOKEN` env 注入，LG-026 P2 通道 cmd 先例）——**会话侧永不接触裸 key**。
- 连带收益（修正令原文）：值班 COS/服务器会话耗用天然进 TriModel 记账（§2.3 第一源）；CFO token 月度总额护栏=**TriModel 层单一断路器**实现（§2.1，免会话侧各自为政）。
- 五件零新发明，逐一映射既有/在建机制：①单列→keys 库**服务器会话单列枚段**；②支出上限→TriModel 额度上限（LG-006 额度接力机制今夜现成，§2.2）；③禁现值→keys 库集中持有（§1.2）；④轮换吊销→keys 库**活枚/死枚轮换**（机制已存在，§1.3）；⑤记账→TriModel 记账落点（LG-006 候裁点随本正身一并落，§2.3）。

### 1.1 五件之①——值班位会话枚段单列禁共用

- 值班位在 keys 库内**单列枚段**（用途名 sg-duty 作枚段标签，非平台侧新申请 key——该动作项经修正令作废）；枚段级隔离=盗刷隔离+审计归因单元（与本地会话枚段禁共用）。
- 归因衔接：枚段单列后 TriModel 网关记账（token_stats）天然按枚段归因（§2.3 第一源成立前提）。
- 共用违例处置：拆段+归因重整；发现共用即在役违例，照 §1.4 分级处置。

### 1.2 五件之③——禁现值入仓入档（权威源分层版）

- **裸 GLM key**：keys 库集中持有，不入仓/不入档/不入会话配置——全盘面（git/文档/快照/台账/cmd/env 文件）现值零容忍；文档与指令只许引用**枚段用途名**不引值。
- **网关令牌 TRIMODEL_API_TOKEN**：会话侧唯一可见凭证，同受密钥纪律（不入仓；注入位=通道 cmd env，LG-026 P2 先例形态）；泄漏处置对象=枚段失效/令牌吊销，非平台 key。
- 晨检断言：裸 key 现值全盘面零命中+网关令牌入仓（env 注入 cmd 之外）零命中（D-18 检索纪律：零命中先疑 pattern 形态再下结论）。
- 违例=泄漏事故级三步：枚段失效/死枚（§1.3）→审计留痕（盘面/时点/写入者）→换活枚/新令牌注入；覆盖+留痕不删除史（D-16/D-18 处置同构）。

### 1.3 五件之④——轮换与吊销口径（keys 库活枚/死枚）

- 轮换触发=**事件驱动+条件式**：泄漏嫌疑/用途变更/授权矩阵人员变动；无变化不轮换（CFO §四倾向同款——高频时钟轮换=快照与额度无谓消耗）。
- 吊销流程=**keys 库活枚转死枚**（机制已存在，LG-006 接力同构）→本件登记簿（批文后启用）→换活枚/新令牌注入→连通验证读数→留痕。

### 1.4 治理结构（谁批/谁注/谁审计/违例处置）

- **谁批**：keys 新增枚与枚段配额=**TriModel 层面事**（CEO 动作清单缩减为**批本正身**）；本正身修订=CEO 批（候审期=BOD 令 2026-09-08 00:5x 两席联合起草）。
- **谁注**：会话 auth 注入=CEO 亲注或显式授权 COS 代注（TRIMODEL_API_TOKEN 通道形态，LG-026 P2 cmd 先例）；**禁裸 key 直注会话**（架构红线）；注入后连通验证读数留痕（M-004 机械回执口径）。
- **谁审计**：CAO 登记面（批文后本件增设登记簿：枚段用途名/开立日/额度值/通道令牌位/状态 活枚·死枚/最近验证读数，首行 sg-duty 候 TriModel 层配置读数）+晨检断言（§1.2）+CFO 月度双源对表（§2.3，第一源=TriModel 网关记账）。
- **违例分级**：裸 key 现值泄漏=事故级（§1.2 三步）；**会话侧现裸 key=架构违例**（红线，即收缴回库+通道改造）；枚段共用=拆段重整；无额度枚段在役=立即补配（§2.2 硬要件）；超总额护栏=升级人工裁不硬断（§2.1——值班位急件断链风险大于超支风险）。

## 二、财务护栏与阈值（CFO 面）

### 2.1 阈值分层：单席口径→总额口径联动

- **单席口径（现行在役，不新立）**：授权矩阵现行分层直接适用——recurring cost >10 USD/月、一次性新增 >100 USD 走升级链（CEOChiefOfStaff→董事会）；值班位月度耗用按此口径对表。
- **公司级月度 token 总额护栏（聚合面，LG-033 M→I 演进触发）**：每加挂一席（值班位→员工 session 级全在线），总额口径重新核算一次。**实现位=TriModel 层单一断路器**（免会话侧碎片化——CEO 修正令 2026-09-08；机制锚=LG-006 额度感知，今夜现成）。**初值设定（建议值候 CEO 批）**：首月观察期只记不设限（读数先行，禁拍脑袋定数）；自第二个月起按首月读数 P50×1.5 定初值；超限=升级人工裁**不硬断**——值班位急件处置不可因预算闸断链，断链风险大于超支风险。

### 2.2 止损阀（五件之②，硬要件）

- **首选形态（修正令后）**：**TriModel 层额度上限+断路器**（LG-006 机制——额度感知触发 402/429 类断/换，token_stats 台账留痕；CEO 修正令 2026-09-08 今夜现成）。损失封顶=值班位枚段配额值——**枚段额度即止损阀刻度**。**建议初值（候 CEO 批）**=值班位月度预期耗用×2（正常耗用+单次异常余量），触发即断/换+走轮换流程（§一之④），不依赖人工发现。
- **候裁项**：原「GLM 平台侧 per-key 配额」实勘项**转候裁**——候 TriModel 层形态对表后裁定是否仍需（CEO 修正令）；若 TriModel 断路器覆盖完整（枚段粒度额度+总额粒度断路两档齐），该项销账。
- **兜底形态（仅裸 key 直连场景若有）**：独立预付额度账户隔离——预付额即损失上限；TRIMODEL_API_TOKEN 通道下会话侧永不接触裸 key，本形态默认不触发。

### 2.3 耗用记账落点细则（五件之⑤）

- **双源归因（修正令后）**：第一源=**TriModel 网关记账**（token_stats 面+值班位枚段归因——五件之⑤落点，LG-006 换棒台账同载体）；第二源=值班位会话侧 token 计量（升级日志分区+会话日志行）。**两源月度对表，差值 >10% 查因**（防计量漂移/异常耗用漏检）。
- **落点（零新建立面，低预算阶段不建重账本）**：周粒度读数入当周 operating records（与 P4' 财务读数门三读数——周 token 耗用/唤醒次数趋势/sg 资源水位——同源同载体，COS 面既有通道）；月粒度对表结论随晨检/周平面记录留痕。**独立账本文件暂不设**（YAGNI：token 读数连续两个月在卷后再议必要性）。
- **取数口径**：P4' 转正判据的财务读数一律取自本节双源，禁凭会话印象估读。

### 2.4 波次联动

- Wave 0（P1 auth 补发）=本正身批文前置（批文到才补发，与 COS 排程一致）；P2 开跑起值班位耗用记账即生效——**读数从第一天开始积累**，P4' 观察周不缺数。
- M→I 演进接口：逐席放行制财务侧=§2.1 总额重核算（TriModel 单一断路器上调档）+§2.2 枚段化逐席复制（缺一席不放一席，枚段额度即止损刻度）。
