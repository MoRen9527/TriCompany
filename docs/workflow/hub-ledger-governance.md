## 一、台账是什么

董事长助理（xiaojia-hub 常驻中枢）维护的**运营级待办追踪器**——追踪所有待办/已办/元项事项，确保"爆上下文→重建→从台账接续"的恢复链不掉链子。

## 二、条目编号规范

| 前缀 | 含义 | 生命周期 |
| --- | --- | --- |
| `LG-XXX` | 挂账事项（业务/工程/运维待办） | 建账→完成销账（或冻结待推进） |
| `M-XXX` | 元项（跨事项长期生效的制度/接线/纪律） | 长期生效，不销账 |

## 三、条目字段规范

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 编号 | ✅ | LG-XXX 或 M-XXX，递增 |
| 事项 | ✅ | 一句话描述 |
| 责任方/窗口 | ✅ | 谁执行、什么时候 |
| 状态 | ✅ | 待执行/进行中/待观测/待排期/待工程窗/待 CEO 裁量/待周检 |
| 销账记录 | 销账时 | 完成时间+结果+证据引用 |

## 五、销账规则

- 完成即销账，附完成时间+结果+证据引用
- 两次周检未动作→冻结退回提案区（对齐登记册降回齿条）
- 不溯及既往：销账后不追改历史条目
